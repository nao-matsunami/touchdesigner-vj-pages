# TouchDesigner VJ Site

TouchDesignerで生成するVJ素材のサンプルを毎日公開する静的サイトです。

GitHub Pages shows a lightweight Canvas preview and the node recipe. Saleable MP4 / alpha MOV masters should be exported from TouchDesigner on the Mac mini.

`offline/create_feedback_network.py` is a TouchDesigner Python starter script.
Run it from a Text DAT to create the first TOP/CHOP feedback network.

## Commands

```sh
npm run daily:update
npm run publish:pages
```
